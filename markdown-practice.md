# Markdown quick start

To create a Markdown file,

1. Choose **File => New**. Name the file using the format **filename.md** (you can choose another filename, but you MUST add the .md suffix).. Hit enter, and you'll be prompted to choose a folder. Be sure to choose a convenient location, like your Documents folder.
2. Write some Markdown (see below for examples).
3. Choose **File => Save** to save the file.

To preview a Markdown file, press **cmd-shift-p** (Mac) or **ctrl-shift-p** (Win) and type "markdown preview." You can choose among the preview options, but I like Open Preview to the Side.

---

Below you'll see some examples of Markdown formatting that can help as you write your blog post.

Tip: Be sure to leave a blank line of space after every heading, paragraph, or list.

## Heading 2
